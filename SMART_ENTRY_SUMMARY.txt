Example 3: Complete Risk Management Stack
```python
from smart_entry import (
    SmartEntryFilter,
    ATRPositionSizer,
    CooldownManager,
    DrawdownCircuitBreaker,
    DailyDealLimiter,
)

# Initialize components
entry_filter = SmartEntryFilter()
sizer = ATRPositionSizer()
cooldown = CooldownManager(cooldown_minutes=30)
breaker = DrawdownCircuitBreaker(max_drawdown_pct=0.10)
limiter = DailyDealLimiter(max_deals_per_day=5)

# Before entering trade
if not entry_filter.should_enter(symbol, "crypto", c1h, c4h, c1d)[0]:
    return  # Entry rejected

if not cooldown.can_trade(symbol):
    return  # Still in cooldown

if not limiter.can_open_deal(bot_id):
    return  # Daily limit reached

if not breaker.check(portfolio_value, peak_value):
    pause_all_trading()  # Circuit breaker tripped
    return

# Size the position
size = sizer.calculate_position_size(candles, balance)

# Open trade
open_trade(symbol, size)
limiter.record_deal(bot_id)
```
